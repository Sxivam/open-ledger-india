# Interactive finance pathways — 10 November 2026

## Reference study

Studied https://roadmap.sh/, its frontend roadmap and its JavaScript roadmap in
native Google Chrome. Observed a connected trunk, alternative branches,
recommendation legend, click-to-open resource panels and step progress controls.
Adapted those interaction principles to Open Ledger's existing cream, forest and
brass identity. Career sequences are editorial guidance rather than prescribed
qualification sequences or fixed hiring timelines.

## Delivered behaviour

- 14 destinations across venture capital, private capital and finance.
- Three alternative entry routes per destination (42 total), each with eligibility
  context and specific actions. Only one route counts toward preparation progress.
- Four shared preparation steps plus the chosen route; optional qualifications and
  the eligibility reference do not inflate the five-step progress total.
- Clickable maps, a linear list view, career search, family filters, task checklists,
  self-assessed progress, browser-local saving and cross-tab synchronization.
- Shareable pathway/route/step links. Shared URLs contain no progress data.
- Downloadable text plans include academic requirements, selected-route eligibility,
  checked tasks, source links and the historical-hiring-example caveat.
- Direct links into relevant opportunity filters, plus separate grades,
  qualifications and source-reference desks.
- Mobile branches stack vertically; the detail drawer uses up to 96% of the viewport.
- Invalid stored values and URL values are validated. If browser storage fails,
  subsequent changes stay in memory for the visit rather than rereading stale data.

  drawer so long explanations have more usable width.

  (`chrome-extension://...`); no application error appeared in that inspection.

Automated checks: lint, TypeScript, production build, existing catalogue checks,
and `verify:pathways` (14 paths, 42 alternatives, valid source references,
five-step counting, corrupted storage and deep-link validation).
